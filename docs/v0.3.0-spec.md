# mactriage v0.3.0 — The Doctor Command

## Goal

Broaden mactriage from app-launch diagnosis into safe, symptom-led everyday Mac
troubleshooting without becoming a cleaner, antivirus product, or background
monitor. Existing commands and machine interfaces remain compatible.

## Commands

- `mactriage doctor` performs a bounded whole-Mac health check covering storage,
  memory and swap pressure, CPU load, descriptor limits, recent crash volume,
  repeatedly restarting processes, security-service availability, macOS update
  availability, installed-app compatibility, login-item count, and network
  configuration. `--severity`, `--only`, and `--skip` filter its results.
- `mactriage network [host]` checks DNS resolution, internet reachability, the
  default route, configured proxies, VPN interfaces, TLS certificate validity,
  and listening socket counts without changing network settings.
- `mactriage relaunch <app>` shows the selected process set and an unsaved-work
  warning. After an explicit default-No confirmation, it sends `SIGTERM`, waits,
  optionally asks separately before `SIGKILL`, reopens the app, and verifies a
  process survives the observation window. JSON and noninteractive runs expose
  the action but never execute it.
- `mactriage baseline save [name]`, `list`, `compare`, and `delete` manage private
  sanitized doctor reports. Files are atomically written with mode `0600` below
  `~/Library/Application Support/mactriage/baselines` by default. Delete is
  confirmation-gated and JSON/noninteractive delete requires `--yes`.
- `mactriage share <report.json|app>` creates a previewable sanitized Markdown
  support report. `--copy` requests clipboard copy after explicit permission;
  no content is uploaded.

## Guided experience and actions

The bare interactive command offers app launch, app slowness, whole-Mac
slowness, network trouble, permissions, baseline comparison, and support-report
paths. Eligible actions remain narrowly allowlisted, explain their effect and
privilege needs, default to No, and are verified after execution.

New safe actions may gracefully relaunch an app, reveal a report in Finder, copy
sanitized Markdown, open Software Update, and run an exact Homebrew upgrade for
a confirmed Homebrew-installed application. v0.3.0 does not remove login items,
delete caches or app data, reset databases, modify security controls, change
DNS/VPN/proxy/firewall configuration, upload reports, or run in the background.

## Output and compatibility

Every diagnostic command supports human and JSON output. Doctor filters affect
both renderers, reports remain sanitized, and existing exit-code semantics are
preserved. Schema changes are additive. Baselines and `--output` files are
atomic and private.

## Acceptance

Tests cover CLI behavior, JSON purity, diagnostic rules through fake runners,
filtering, atomic baseline storage, report sanitization, and recovery permission
paths. Acceptance includes formatting, vet, race tests, macOS integration tests,
vulnerability scanning, both Darwin architectures, GoReleaser packaging,
Homebrew formula CI, and a public upgrade smoke test.
